## 📋 Features Implemented

| Feature | Description |
|---|---|
| 🔗 **Navigation Highlight** | Active nav link is highlighted; only one active at a time |
| 📂 **Dropdown Menu** | "Explore" nav item reveals a nested dropdown on click |
| 🍔 **Hamburger Menu** | On mobile screens, a hamburger icon toggles the nav menu |
| ✍️ **Text Manipulation** | "Inspire Me" button cycles through motivational quotes; Reset restores original |
| 🌙 **Dark / Light Mode** | Toggle button switches between dark and light themes using CSS variables |
| 💬 **Input & Display** | User types into a field; clicking Display shows the message on screen |
| ➕ **Dynamic List** | Users can add bucket-list items dynamically without page reload |
| 🗑 **Element Removal** | Clicking any list item removes it with a smooth animation |
| 🔍 **Search / Filter** | Real-time search filters the list as the user types |
| 🃏 **Activity Cards** | 6 activity cards — each card's button adds the activity to the list and selected section |
| 🎴 **Selected Activities** | A tag-based panel shows all activities chosen from the cards |
| 🔔 **Toast Notifications** | Feedback toasts appear on user actions |
| 📱 **Responsive Design** | Fully responsive for mobile, tablet, and desktop |

---

## 🛠 What This Project Demonstrates

- DOM selection with `getElementById`, `querySelector`, `querySelectorAll`
- Event listeners for `click`, `input`, `keydown`
- Dynamic element creation and removal (`createElement`, `appendChild`, `remove`)
- Style manipulation with CSS custom properties (variables)
- Class toggling for interactivity (`classList.toggle`, `.add`, `.remove`)
- Content filtering using `.textContent` and `.hidden` class
- Smooth transitions and animations using CSS + JS
